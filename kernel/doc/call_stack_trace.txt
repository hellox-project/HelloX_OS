Following compile flags must be set to support call stack trace:
/Oy-, i.e, disable omit_frame_pointer option. Only in this case, the EBP will be
used as stack frame, so the call stack could be traced by EBP register.
Otherwise the EBP maybe used as general register by compiler, the call stack
could not be obtained.

The source code of CST(cst.h/cst.c) is generated by AI, but be reviewed and 
tested carefully by Garry.Xin.

Other compile options are /O1, /Ob1, please check the project properties.
